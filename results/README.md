# Results

The performance of the existing and proposed protocols was evaluated using five PARSEC benchmarks:

- Blackscholes
- Bodytrack
- Canneal
- Dedup
- Facesim

## Performance Metrics

The comparison includes:

- Simulation Time
- Simulated Operations
- Simulated Instructions
- Average Host Tick Rate
- IPC
- CPI
- Cache Hit Rate
- Cache Miss Rate
- Average Latency
- Network Traffic
- Average Memory Access Time (AMAT)

## Result Summary

The proposed algorithm shows improved processor efficiency and memory/network performance across the evaluated benchmarks.

The results indicate:

- Higher IPC and lower CPI
- Reduced cache miss rate and improved cache hit rate
- Lower average latency
- Reduced network traffic
- Reduced AMAT
- Improved execution performance
